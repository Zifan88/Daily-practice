\# Exploratory Testing Checklist



\*\*Purpose:\*\* A reusable checklist to guide exploratory testing of any web application.



\## Session Charter (fill before each session)

\- \*\*Application / Feature:\*\*

\- \*\*Goal:\*\* (e.g., Find issues in the checkout flow)

\- \*\*Time box:\*\* 30 minutes

\- \*\*Tester:\*\*

\- \*\*Date:\*\*



\## 1. Functionality

\- \[ ] All buttons and links work as expected

\- \[ ] Forms submit correctly with valid data

\- \[ ] Required field validations are shown for empty fields

\- \[ ] Error messages are clear and accurate

\- \[ ] Search, filter and sort features return correct results



\## 2. Input Validation

\- \[ ] Very long text in input fields

\- \[ ] Special characters (e.g., `<>\&"'%`)

\- \[ ] Leading and trailing spaces

\- \[ ] Negative numbers, zero and very large numbers

\- \[ ] Boundary values (minimum and maximum allowed)



\## 3. Usability

\- \[ ] Navigation is clear and consistent

\- \[ ] Labels and messages have no spelling mistakes

\- \[ ] Tab key moves through fields in a logical order

\- \[ ] Success and failure feedback is visible to the user



\## 4. Compatibility

\- \[ ] Works in Chrome, Firefox and Edge

\- \[ ] Layout works on mobile screen sizes

\- \[ ] Browser back and refresh do not break the flow



\## 5. Security Basics

\- \[ ] Password fields are masked

\- \[ ] Protected pages are not accessible without login

\- \[ ] Session expires after logout



\## 6. Performance

\- \[ ] Pages load within an acceptable time

\- \[ ] No freezing when performing repeated actions
